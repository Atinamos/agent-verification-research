# Decision Delta v0.1 — Readiness Checklist

This checklist mirrors the public tracking issue and records the pre-run gate for Protocol v0.1.

- [x] Publish pre-run protocol draft
- [ ] Review protocol for methodological bias or missing controls
- [ ] Policy evaluation treats endpoint + HTTP method as evidence identity
- [ ] Fulfilment and correctness are represented/evaluated separately
- [ ] Freeze primary buyer policy JSON
- [ ] Build paired control/evidence-assisted experiment runner
- [ ] Define and freeze 6–8 real scenarios
- [ ] Snapshot candidate contracts, prices, methods and networks
- [ ] Dry-run with no live spend
- [ ] Freeze Protocol v0.1 and record version/hash
- [ ] Run matched live experiments
- [ ] Publish sanitised dataset, receipts, analysis and limitations

**Gate rule:** no live Decision Delta purchase runs occur until all pre-run items through protocol freeze are complete.
